# ESP32

The **ESP32** is a low-cost, low-power system-on-a-chip (SoC) featuring built-in 2.4 GHz Wi-Fi and dual-mode Bluetooth. Developed by Espressif Systems, it is widely used for Internet of Things (IoT) projects, smart home automation, and wireless sensors due to its high performance and versatile general-purpose input/output (GPIO) pins.

---

## Key Features

The ESP32 is highly popular in the electronics community due to several standout features:

* **Low Cost**: Available starting at approximately $6, making it highly accessible for developers and hobbyists.
* **Low Power**: Consumes minimal energy and supports advanced low-power states like *deep sleep* to conserve battery life.
* **Wi-Fi Capabilities**: 
  * **Station Mode**: Connects easily to existing Wi-Fi networks to access the internet.
  * **Access Point Mode**: Creates its own wireless network so other devices can connect directly to it.
* **Bluetooth Support**: Supports both Bluetooth Classic and Bluetooth Low Energy (BLE), which is ideal for power-sensitive IoT applications.
* **Dual-Core Processor**: Most variants feature two Xtensa 32-bit LX6 microprocessors (Core 0 and Core 1) for multitasking.
* **Rich Peripheral Interfaces**: Supports a wide variety of inputs and outputs, including:
  * Capacitive touch sensors
  * Analog-to-Digital Converters (ADC) and Digital-to-Analog Converters (DAC)
  * Communication protocols: UART, SPI, and I2C
  * Pulse-Width Modulation (PWM)
* **Arduino Compatible**: Can be programmed using the familiar Arduino IDE and programming style.
* **MicroPython Support**: Compatible with MicroPython firmware, allowing developers to write scripts using Python 3 syntax optimized for embedded systems.
